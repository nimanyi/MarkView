MDViewer 使用说明

简介

MDViewer 是一款跨平台 Markdown 编辑 / 预览应用：左侧编辑、右侧实时预览， 解析由 Rust 端 comrak 完成（完整 GFM 支持），内建 KaTeX 数学公式与 Mermaid 图表渲染， 支持导出独立 HTML 与 PDF、文件树管理、大纲导航、全文搜索和自动更新。

界面

  • 侧边栏（Ctrl+\）：文件树 / 文档大纲 / 全文搜索三个标签页
  • 编辑区：顶部排版工具栏随光标高亮当前格式，可用 Alt+T 收起
  • 中缝分隔条：拖动调节编辑 / 预览宽度，双击复位
  • 自动保存：打开的文件停止输入 2 秒后自动写回（设置中可关闭）

全局快捷键

Ctrl+N新建文档
Ctrl+O / Ctrl+Shift+O打开文件 / 打开文件夹
Ctrl+S / Ctrl+Shift+S保存 / 另存为
Ctrl+Shift+E / Ctrl+P导出 HTML / 打印・PDF
Ctrl+\切换侧边栏
Alt+T显示 / 隐藏排版工具栏
Ctrl+Shift+L循环切换主题
Ctrl+Shift+F全文搜索
Ctrl+, / Ctrl+Shift+H设置 / 本说明
Ctrl+Shift+U检查更新

编辑器排版快捷键（光标在编辑器内）

Ctrl+B / Ctrl+I加粗 / 斜体
Ctrl+E / Ctrl+Shift+X行内代码 / 删除线
Ctrl+K插入链接（选区作链接文字）
Ctrl+1 ~ Ctrl+6设为 H1~H6 标题（同键再按取消）

以上均为 toggle 语义：已包裹再按一次即取消；工具栏按钮与快捷键行为一致。
