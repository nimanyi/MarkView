MDViewer 使用说明

简介

MDViewer 是一款跨平台 Markdown 编辑 / 预览应用：左侧编辑、右侧实时预览，解析由 Rust 端 comrak 完成（完整 GFM 支持），内建 KaTeX 数学公式与 Mermaid 图表渲染，支持导出独立 HTML 与 PDF、文件树管理、大纲导航、全文搜索和自动更新。

界面

  • 侧边栏（Ctrl+\）：文件树 / 文档大纲 / 全文搜索三个标签页
  • 视图模式（Ctrl+Shift+V）：双栏 / 仅编辑 / 仅预览，设置面板中同样可选
  • 右键菜单：按位置提供剪切 / 复制 / 粘贴、复制链接等（浏览器默认菜单已屏蔽）
  • 编辑区：顶部排版工具栏随光标高亮当前格式，可用 Alt+T 收起
  • 中缝分隔条：拖动调节编辑 / 预览宽度，双击复位
  • 设置（Ctrl+,）：主题三态、颜色风格（内置 / 自定义 7 色调色板，实时预览；可导入 / 导出 JSON 与人分享——风格市场的分发格式）、界面 / 编辑器 / 预览字号
  • 自动保存：打开的文件停止输入 2 秒后自动写回（设置中可关闭）
  • 多标签：可同时打开多份文档，点击标签或 Ctrl+Tab 切换，Ctrl+W / 中键关闭；右键标签可批量关闭左侧 / 右侧 / 其他 / 所有；标签圆点亮起表示有未保存修改，打开新文件不会打断当前编辑
  • 引导页：启动或关闭全部标签时显示，提供新建 / 打开文件 / 打开文件夹 / 使用说明的快捷入口
  • 拖放打开：将 .md / .markdown / .mdx / .txt 文件直接拖入窗口即可打开

全局快捷键

Ctrl+N新建文档
Ctrl+O / Ctrl+Shift+O打开文件 / 打开文件夹
Ctrl+S / Ctrl+Shift+S保存 / 另存为
Ctrl+W关闭标签页
Ctrl+Tab / Ctrl+Shift+Tab下一个 / 上一个标签
Ctrl+Shift+E / Ctrl+P导出 HTML / 打印・PDF
Ctrl+\切换侧边栏
Ctrl+Shift+V切换视图（双栏 / 仅编辑 / 仅预览）
Ctrl+Shift+D隐藏 / 显示预览（仅编辑 ↔ 双栏）
Alt+T显示 / 隐藏排版工具栏
Ctrl+Shift+L循环切换主题
Ctrl+Shift+F全文搜索
Ctrl+, / Ctrl+Shift+H设置 / 本说明
Ctrl+Shift+U检查更新

编辑器排版快捷键（光标在编辑器内）

Ctrl+B / Ctrl+I加粗 / 斜体
Ctrl+E / Ctrl+Shift+X行内代码 / 删除线
Ctrl+K插入链接（选区作链接文字）
Ctrl+1 ~ Ctrl+6设为 H1~H6 标题（同键再按取消）

以上均为 toggle 语义：已包裹再按一次即取消；工具栏按钮与快捷键行为一致。
